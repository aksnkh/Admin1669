# طرح پیشنهادی گزارش سفارش‌ها — نسخه ۲

این پوشه فقط پیش‌نمونهٔ طراحی است و برنامهٔ اصلی و API را تغییر نمی‌دهد.
تمام اطلاعات نمایش‌داده‌شده ساختگی‌اند؛ هیچ درخواست API یا پیامکی ارسال نمی‌شود.

## Preview

- `preview-desktop.png`: نمای کامل دسکتاپ، عرض ۱۴۴۰ پیکسل
- `preview-details.png`: پنل جزئیات سفارش
- `preview-mobile.png`: نمای موبایل، عرض ۳۹۰ پیکسل
- `index.html`: پیش‌نمونهٔ تعاملی مستقل؛ فایل را دانلود و در مرورگر باز کنید. فونت در HTML تعبیه شده و اینترنت لازم نیست.

فیلترها، جست‌وجوی همین صفحه، پاک‌کردن فیلترها، جزئیات سفارش، خروجی CSV نمونه، انتخاب تعداد سطر و منوی موبایل قابل آزمایش هستند. ناوبری سایر صفحات و ثبت ارجاع فقط دکمه‌های نمایشی‌اند. شمارنده‌ها متعلق به همان صفحه هستند، نه آمار کل سیستم. صفحه‌بندی چندصفحه‌ای در این پیش‌نمونه به دادهٔ واقعی متصل نیست.

## استفاده در Figma

فایل `orders-report-figma.svg` را در یک فایل Figma به داخل canvas بکشید و در صورت نیاز Ungroup کنید. فایل شامل شکل‌های برداری و متن‌هاست؛ فایل بومی `.fig`، کامپوننت‌های Figma یا Auto Layout نیست. متن‌ها ممکن است بسته به فونت نصب‌شده جایگزین شوند. برای تطبیق دقیق فونت، از نسخهٔ دارای مجوز و قابل نصب فونت پروژه استفاده کنید؛ فایل WOFF2 و اعلان اصلی مجوز نیز همراه طرح حفظ شده‌اند.

نسخهٔ HTML و تصاویر PNG مرجع ظاهر صحیح طرح هستند. ایجاد فایل مستقیم در Figma در این جلسه به‌علت نبود ابزار فعال طراحی Figma انجام نشده است.

## تصمیم‌های طراحی

- فضای کاری فارسی و راست‌به‌چپ، آبی اصلی `#245FE5` و پس‌زمینهٔ `#F5F7FB`
- فیلترهای شش‌گانه مطابق قرارداد جدید گزارش، جدا از ابزارهای جدول
- ادغام اطلاعات مرتبط در ستون‌های دوخطی: مشتری/تماس، دستگاه/برند، شهر/منطقه و تاریخ/ساعت
- انتقال جزئیات طولانی به پنل جانبی با پشتیبانی Escape و بازگرداندن focus
- نمایش وجود یا نبود تکنسین ارجاع با رنگ و متن؛ بدون اختراع وضعیت‌های جدید بک‌اند
- منوی موبایل، اسکرول مستقل جدول و حالت بدون نتیجه

تست مرورگر برای فیلتر و پاک‌کردن، جست‌وجو، جزئیات، CSV نمونه و منوی موبایل اجرا شده است. نمای ۳۹۰ پیکسلی بدون overflow افقی صفحه بررسی شده است.
