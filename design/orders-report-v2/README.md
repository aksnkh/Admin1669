# طرح اصلاح‌شدهٔ گزارش سفارش‌ها — جدول کامل

بر اساس بازخورد مالک پروژه، هر ۱۷ ستون جدول در همان ترتیب اصلی حفظ شده‌اند:
کد، دستگاه، برند، مشکل دستگاه، شهر، منطقه، نام خانوادگی، تعداد تعمیرات انجام شده، زمان ثبت سفارش، تلفن، موبایل، نام تکنسین، توضیحات، اپراتور، استان، ارجاع به، ثبت اقدام.
هیچ ستونی ترکیب یا به پنل جزئیات منتقل نشده است. کارت‌های آماری و پنل جزئیات طرح قبلی حذف شده‌اند.

## چیدمان

- هدر گزارش: عنوان، تعداد نتایج نمونه، به‌روزرسانی، دریافت خروجی و تمام‌صفحه.
- بخش فیلتر در هدر جدول: دستگاه، برند، ایراد، استان، شهر، منطقه و تکنسین؛ همراه اعمال/حذف فیلتر و نمایش انتخاب‌های فعال.
- بدنه: همان جدول کامل، با رنگ‌بندی و فاصله‌گذاری ملایم و اسکرول مستقل افقی در صفحه‌های کوچک.
- فوتر گزارش: تعداد نمایش، بازهٔ سطرهای فعلی و کنترل‌های صفحه‌بندی.

این پوشه فقط پیش‌نمونهٔ طراحی است. سورس برنامهٔ اصلی، API و قراردادهای بک‌اند تغییر نکرده‌اند. اطلاعات ساختگی و شماره‌ها ماسک‌شده‌اند.
فیلتر «ایراد» برای حفظ ظاهر فیلترهای تصویر مرجع در پیش‌نمونه موجود است؛ اتصال آن به بک‌اند، نیازمند پشتیبانی در قرارداد API است و در این طراحی اضافه نشده است.

## Preview و دانلود

`preview-desktop.png` نمای ۱۹۲۰ پیکسلی و `preview-mobile.png` نمای ۳۹۰ پیکسلی است.
`design-package.zip` شامل پیش‌نمونه، Previewها و SVG است.
`index.html` مستقل است: آن را دانلود و در مرورگر باز کنید. فونت تعبیه شده و به اینترنت نیازی ندارد.
فیلتر، پاک‌کردن، مرتب‌سازی ستون‌ها، صفحه‌بندی، تعداد نمایش و خروجی CSV نمونه قابل آزمایش هستند. هیچ درخواست API ارسال نمی‌شود.

## Figma

فایل `orders-report-figma.svg` را روی Canvas فیگما بکشید و در صورت نیاز Ungroup کنید. فایل شامل شکل‌های برداری و متن است؛ فایل بومی `.fig` یا Auto Layout نیست. متن ممکن است با توجه به فونت نصب‌شده جایگزین شود. HTML و PNG مرجع ظاهر طرح هستند. برای تطبیق کامل از نسخهٔ دارای مجوز و قابل نصب فونت پروژه استفاده کنید. فونت ارائه‌شده و اعلان مجوز اصلی همراه طرح حفظ شده‌اند.

تست مرورگر برای وجود تمام ۱۷ ستون، فیلتر/پاک‌کردن، صفحه‌بندی رفت‌وبرگشت، تعداد نمایش، مرتب‌سازی، CSV و نبود overflow افقی کل صفحه در موبایل موفق بوده است.
